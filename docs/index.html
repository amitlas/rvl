Downloading rvl.zip... If nothing happens, click here.

Then (works in any Chrome language):

  1. Extract the zip (Windows: right-click it, Extract All).
  2. Type chrome://extensions in the address bar.
  3. Turn on the only switch at the top of the page (Developer mode).
  4. Drag the extracted rvl folder onto that page and drop it.

Keep the folder: Chrome runs the extension from it.
